# ScanForge 点云后处理最小 Demo

这是一个独立的 Qt6/C++17 点云后处理 Demo，界面参考 `../prev/preview.html`。点云显示使用 OpenGL，PCD 读取使用内置二进制解析器，避免 Qt6 与系统中 PCL/VTK 的 Qt5 依赖冲突。

当前垂直流程：

1. 导入 PCD（优先验证 `../prev/cloud_color_optimized.pcd`）；
2. OpenGL 点云显示、旋转、平移、缩放和适配视图；
3. XYZ 范围实时裁剪预览；点击“应用裁剪”写入处理记录；
4. 区域删除、半径离群过滤、体素降采样和地面拟合调平：设置参数后预览前后点数，再应用到撤销记录；
5. 多条两点测量记录，标注坐标单位、坐标系和处理步骤，支持删除选中记录和导出全部测量 CSV；
6. PCD/PLY 导出当前可见的点云（有裁剪或处理预览时导出预览结果）、测量 CSV 和截图。

导入后保留原始点云；裁剪和变换按当前文件树节点记录，支持编辑菜单或 Ctrl+Z/Ctrl+Shift+Z 撤销、重做。撤销到中间步骤再编辑会丢弃其后的重做记录。预览只影响显示和本次导出，不写入记录；应用裁剪后才改变当前点云。显示端最多采样 150 万点，但裁剪和导出使用完整点云。PCD 导入和导出均采用 `DATA binary`，输出字段为 `x y z rgb`（float32 坐标、8 位 RGB）；不能覆盖最初导入的 PCD。处理记录只保存在当前程序会话中。

离群过滤使用指定半径内至少 N 个其他点；体素输出位置与颜色均为体素内均值。地面拟合假定 Z 轴向上，优先用 XYZ 范围框选地面作为拟合样本，随后将求得的变换作用于整云；界面显示候选点、内点比例、RMS 和倾角。没有可信平面时拒绝预览和应用。PCD 不包含可可靠读取的长度单位或坐标系名，因此两者默认“未指定”，需要操作者自行标注；测量数值沿用原始坐标单位，软件不会进行单位换算。PCD/PLY 也不保存这些手工标注，CSV 会保存每条测量时的标注与处理步骤。
新开 PCD 时单位和坐标系标注复位；旋转或调平后坐标系标注清空，需要重新确认。历史测量保留创建时的标注。

## 真实数据验收

2026-09-29，使用 `../prev/cloud_color_optimized.pcd`（10,656,295 点）在本机单次运行：

| 处理 | 参数（输入坐标单位未标注） | 结果点数 | 处理时间 | 峰值 RSS（含导入、导出和重开） |
| --- | --- | ---: | ---: | ---: |
| 体素降采样 | 边长 0.03 | 2,969,787 | 1.08 s | 约 700 MiB |
| 半径离群过滤 | 半径 0.05、至少 3 邻点 | 10,388,190 | 11.90 s | 约 1,131 MiB |
| 调平选区 | Z [-13, -11]、容差 0.05 | 10,656,295 | 0.25 s | 约 1,153 MiB |

三项处理结果导出 PCD 并重开后，点数、坐标与导出时的 8 位 RGB 通道逐点一致。体素均值颜色写入 PCD 时会量化到 8 位。全图默认地面拟合未通过置信门槛；上述调平选区得到 42,141 个候选点、10,657 个内点（25.3%）、RMS 0.0276（坐标单位）、拟合倾角 0.799°。它证明该选区可拟合并导出，**不证明**整图倾斜 0.799° 或该平面一定是真实地面；仍需现场地面/重力参考验收。时间为当前机器的单次测量，不代表其他硬件性能。

应用层另用无窗口 Qt 测试加载同一文件并完成体素预览、应用、撤销：加载 229 ms、预览 1.20 s、应用 45 ms、撤销 100 ms，峰值 RSS 约 854 MiB。该测试覆盖文件到界面状态的连接，不测 OpenGL 实际绘制帧率。

## 构建

需要 Qt6（Widgets、OpenGLWidgets、Concurrent）、Eigen3 和 `nanoflann.hpp`（Debian/Ubuntu 包 `libnanoflann-dev`）。此目录带 `COLCON_IGNORE`，作为独立 Qt Demo 用 CMake 构建。

```bash
cd /home/rain/ros_ws/handler_ws/app/pointcloud_demo
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

## 运行

```bash
./run_demo.sh
```

不带参数时只启动空界面，点击“打开 PCD”后再选择点云。也可以显式传入点云路径，让程序启动时自动加载：

```bash
./run_demo.sh ../prev/cloud_color_optimized.pcd
```
